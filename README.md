# Astro Courier

A polished, dependency-free browser game for a portfolio. Fly through deep
space, collect energy crystals, avoid asteroids, and beat the local high score.

## Run

Open `index.html` in a browser. No installation is required.

For a local server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Features

- Canvas-based game loop with keyboard controls
- Responsive layout for desktop and mobile screens
- Progressive difficulty with levels
- Score, crystal count, and persistent high score
- No framework or external runtime dependency
